# DevOps E-Commerce Platform

End-to-End DevOps implementation of a polyglot microservices
e-commerce platform.

## Project Goal

Build and deploy a production-style microservices application
progressively from local development to AWS.

## Technology Stack

- Python
- Node.js
- Java / Spring Boot
- PostgreSQL
- Redis
- Kafka
- Docker
- Kubernetes
- Helm
- Terraform
- AWS
- GitHub Actions
- Argo CD

## Development Approach

Local development → Docker → Kubernetes → AWS → EKS → GitOps → CI/CD
